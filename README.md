# Table-XY
Development of a Table XY based on 4xiDraw

Directories:  
- achats: 
	- Components bought

- assembly: 
	- detail of the assembly of the Table XYComponents to be bought, related actions

- hardware: 
	- documents related to Electronic hardware

- mechanic: 
	- Mechanic elements
		- mechanic / docs: documents related to mechanic elements
		- mechanic / Files: documents related to mechanical elements to be constructed (using Printer 3D)
		- mechanic / Printer3D-Prusa: documents related to Prusa Printer-3D elements created and printed

- photos: 
	- Photos of the assembly steps

- software: 
	- programs and related elements
		- software / Arduino: Arduino related programs R3 / R4	
		- software / gcode: GRBL files for testing system behaviour
		- software / Inkscape: source files for Inkscape program
		- software / python: Python script for transferring GCode to Arduino without using UCode Sender


- wiki: 
	- elements for wiki page
		- wiki / images: Images
		- wiki / docs: Documents.
